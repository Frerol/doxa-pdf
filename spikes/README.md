# Spikes (throwaway prototypes)

Code here lives only on `spike/*` branches and is never merged into `main`. Findings are in `docs/spikes/` on `main`.

- `render_probe/`: Spike A, desktop. PDFium cost per operation (`bin/render_probe.dart`) and hiding Doxa annotations in a render instance (`bin/hidden_probe.dart`).
- `render_lab/`: Spike A, Android. Engine isolate, previews, tiles, LRU cache, fling and pinch zoom; logs `RENDERLAB` lines.
